Set up this device

Three steps: get the store's certificate, trust it, then pair. About two minutes.

1. Get the store certificate

It lets this device talk to the hub securely. It is made by this store's hub and is used for nothing else.

Download certificate

2. Trust it

iPhone or iPad
  1. Tap Download certificate, then Allow. You see "Profile Downloaded".
  2. Open Settings. Tap Profile Downloaded near the top (or General → VPN & Device Management).
  3. Tap Install, enter your passcode, and tap Install again.
  4. Go to Settings → General → About → Certificate Trust Settings.
  5. Turn on Chedam Store CA and tap Continue. This step is easy to miss.
  6. Come back to Safari and do step 3.
Android 9 or older
  1. Tap Download certificate.
  2. If asked to name it: type Chedam, choose VPN and apps, tap OK. (Android asks for a screen lock if the phone has none.)
  3. If nothing appears: Settings → Security & location → Advanced → Encryption & credentials → Install from storage, then pick the downloaded file.
  4. Always open the hub by its number (like 192.168.50.101), not by chedam.local. Android 9 cannot find .local names.
Android 10 or newer
  1. Tap Download certificate.
  2. Open Settings and search for CA certificate. On most phones it is Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate.
  3. Tap Install anyway, then pick the downloaded Chedam-Store-CA file.
  4. Come back to the browser and do step 3.
Windows PC
  1. Download the certificate and open it. Click Install Certificate…
  2. Choose Current User, then Place all certificates in the following store → Browse → Trusted Root Certification Authorities.
  3. Click Next → Finish, then Yes on the security warning.
  4. Close all browser windows and open this page again.
Mac
  1. Download the certificate and open it. It is added to Keychain Access.
  2. Double-click Chedam Store CA, open Trust, set When using this certificate to Always Trust.
  3. Close the window and enter your Mac password.

3. Check and pair

Tap the button. If the certificate is trusted, the pairing page opens.
